# Ceremonies — explicit planning work only

No scheduled or automatic ceremonies are enabled. No ceremony may create issues, commit, push, launch unattended agents or activate Ralph.

| Ceremony | Trigger | Owner | Required outcome |
|----------|---------|-------|------------------|
| Discovery review | Explicit assignment at Phase 0 exit | Morpheus | Evidence coverage, baseline limitations, preservation contract |
| Knowledge/retrieval design review | Explicit assignment at Phase 1/2 exit | Neo / Switch | Provenance/schema contract and fair baseline comparison |
| Quality and claim review | Explicit assignment before final plan approval | Tank / Fact Checker | Evaluability, citations, unknowns and contradictions |
| Responsible AI review | Explicit assignment before ingestion/design approval | Rai | Privacy, untrusted-input boundaries, deletion and external-data rules |
| Decision record | Explicit session handoff | Scribe | Append-only local decisions/histories, no automatic commit |
| Retrospective | Explicit request after a failed gate | Morpheus | Local lessons and phase-relative actions, never automatic GitHub issues |
